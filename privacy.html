プライバシーポリシー

kihon-uploader(以下「本ツール」)は、制作者本人が自分の YouTube チャンネルに動画をアップロードするための個人用ツールです。

利用する Google のデータ

本ツールは YouTube Data API の「動画のアップロード」(youtube.upload)、Instagram の投稿権限、TikTok の動画アップロード(video.upload)だけを使い、制作者本人のアカウントへの動画の投稿のみを行います。それ以外のアカウントのデータは読み取りません。

データの保存と共有

認可情報(トークン)は、制作者本人が管理する環境にだけ保存し、第三者に提供・販売することはありません。

アクセスの取り消し

Google アカウントの「サードパーティ製のアプリとサービス」(https://myaccount.google.com/connections)から、いつでも本ツールのアクセスを取り消せます。

Google API から受け取った情報の使用は、Google API サービスのユーザーデータに関するポリシー(限定使用の要件を含む)に従います。
